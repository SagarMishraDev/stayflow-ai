StayFlow widget — demo & test page

This page stands in for a hotel's own website. Paste the hotel's public id (Staff dashboard → Hotel settings → Integrations) and load the widget exactly the way a real site would.

The embed snippet a hotel pastes into its website is: 
<script src="https://YOUR_HOSTED_DOMAIN/widget.js"
        data-hotel-id="HOTEL_PUBLIC_ID" async></script>
Once loaded, the 💬 launcher appears at the bottom-right of this page.
